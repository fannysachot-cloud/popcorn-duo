Popcorn Duo marche sur ordinateur, dans Google Chrome (ou Edge, Brave, Arc). Ouvre ce lien sur ton ordinateur, avec l'un de ces navigateurs.

Installer Popcorn Duo

Clique sur « Ajouter à Chrome », puis confirme. Ensuite, tu arrives automatiquement dans la séance.

Télécharger Popcorn Duo
  1. Ouvre le fichier téléchargé : un dossier popcorn-duo apparaît. Range-le dans Documents (il doit y rester).
  2. Dans Chrome, va sur chrome://extensions.
  3. Active Mode développeur (en haut à droite).
  4. Glisse le dossier popcorn-duo sur cette page.

Tu arrives ensuite automatiquement dans la séance.

Déjà installé ? Recharge cette page.
